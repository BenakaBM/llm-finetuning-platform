# API Reference

Full interactive documentation is auto-generated by FastAPI and served at
`http://localhost:8000/docs` (Swagger UI) and `http://localhost:8000/redoc`.

## Authentication

```
POST /api/auth/register   { email, password, full_name? }        -> 201 UserResponse
POST /api/auth/login      { email, password }                    -> 200 { access_token, token_type }
```

All other endpoints require `Authorization: Bearer <token>`.

## Datasets

```
POST   /api/datasets                         multipart form: file, name, description?
GET    /api/datasets
GET    /api/datasets/{id}
GET    /api/datasets/{id}/versions
GET    /api/datasets/versions/{version_id}/preview
DELETE /api/datasets/{id}
```

## Models

```
GET  /api/models
POST /api/models        { name, base_model_id, architecture?, parameter_count?, context_length? }
GET  /api/models/{id}
```

## Training

```
POST /api/training/jobs                       { dataset_version_id, base_model_id, experiment_name, config, max_train_samples? }
GET  /api/training/jobs
GET  /api/training/jobs/{id}
GET  /api/training/jobs/{id}/metrics
GET  /api/training/jobs/{id}/stream            Server-Sent Events: live status/loss updates
POST /api/training/jobs/{id}/cancel
```

## Evaluations

```
POST /api/evaluations       { experiment_id, evaluation_type, dataset_version_id, model_version_id?, max_samples?, metrics? }
GET  /api/evaluations?experiment_id=...
GET  /api/evaluations/{id}
```

## Experiments

```
GET  /api/experiments
GET  /api/experiments/{id}                     Full detail: training curves, comparison, samples
POST /api/experiments/compare                  body: ["exp-id-1", "exp-id-2", ...]  (2-4 ids)
```

## Playground

```
POST /api/playground/generate   { model_version_id? | base_model_id?, prompt, temperature?, top_p?, max_tokens? }
```

## Dashboard & System

```
GET /api/dashboard/summary
GET /api/system/info             Hardware detection (CPU/CUDA/GPU memory)
```

## Error format

All errors are returned in a consistent shape:

```json
{
  "success": false,
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "Dataset contains invalid records."
  }
}
```
